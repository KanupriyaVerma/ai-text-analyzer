# 🤖 AI Text Analyzer

AI Text Analyzer is a full-stack web application that analyzes user text and provides useful insights such as sentiment detection, summaries, keyword suggestions, and word count.

The project was built to explore AI-powered text processing concepts while combining backend API development with an interactive frontend experience.

---

## 🚀 Features

* Sentiment Analysis
* Text Summary
* Keyword Suggestions
* Word Count Analysis
* Chat-style User Interface
* Voice Input Support
* Input Validation
* Responsive Design

---

## 🛠️ Tech Stack

### Backend

* Python
* Flask
* Flask-CORS

### Frontend

* HTML

## ▶️ Run Locally

### Install dependencies

```bash
pip install flask flask-cors
```

### Run the backend

```bash
python app.py
```

### Open frontend

Open `index.html` in your browser.
